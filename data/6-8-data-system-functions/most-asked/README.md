# Most asked: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.8: What a data system does](https://mitsurutech.co.uk/resources/t-level/dsd-6-8-data-system-functions)

## What to do

A shop keeps a list of the products people ask for. Fill in four functions. The first adds a request. The second counts the requests for one product. The third gives back the product asked for most often. The fourth says if the shop should buy more.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
