# Sensor stream: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.7: Big Data and the six Vs](https://mitsurutech.co.uk/resources/t-level/dsd-6-7-big-data-six-vs)

## What to do

A tracker sends readings all the time. Fill in the four functions. The first counts readings. The second finds the busiest second. The third says if the stream is fast. The fourth works out the storage.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
