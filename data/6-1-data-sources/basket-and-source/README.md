# Basket and source: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.1: Where data comes from](https://mitsurutech.co.uk/resources/t-level/dsd-6-1-data-sources)

## What to do

A shop records each sale as a basket. A basket is a list of pairs: the item name and the price. Fill in the three functions. The first counts the items. The second adds up the prices. The third says what kind of source a device is.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
