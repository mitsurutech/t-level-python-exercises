# Failed logins: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.1: How organisations use data](https://mitsurutech.co.uk/resources/t-level/dsd-6-1-how-organisations-use)

## What to do

A security team watches the logins. Each login is a pair: the username and True or False for worked. Fill in two functions. The first counts the failed logins for one user. The second lists the users who failed 2 times or more.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
