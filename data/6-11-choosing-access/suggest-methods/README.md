# Suggest methods: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.11: Choosing how to give access](https://mitsurutech.co.uk/resources/t-level/dsd-6-11-choosing-access)

## What to do

Two steps. Read the comments in the starter for the exact rules. 1. suggest_methods gets two facts about a system and gives back a list of access methods. 2. risk_level rates the risk as "high", "medium" or "low".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
