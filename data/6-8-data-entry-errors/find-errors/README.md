# Find errors: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.8: Data entry errors and how to stop them](https://mitsurutech.co.uk/resources/t-level/dsd-6-8-data-entry-errors)

## What to do

Write four small functions for a data entry system. The first counts the places where two texts differ. The second finds a transposition. The third names the type of error. The fourth checks a phone number. Read the comments in the starter.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
