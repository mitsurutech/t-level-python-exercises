# Codes and bytes: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.5: ASCII and UTF-8](https://mitsurutech.co.uk/resources/t-level/dsd-6-5-ascii-and-utf-8)

## What to do

Fill in the four functions with ord and chr. 1. char_code gives the code of one letter. 2. next_letter gives the letter after it. 3. secret_word turns a list of codes into a word. 4. is_ascii gives True if every character has a code below 128. The tests use real characters from French and Japanese.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
