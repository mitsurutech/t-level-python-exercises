# Text bar chart: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.9: Ways to show data](https://mitsurutech.co.uk/resources/t-level/dsd-6-9-visual-formats)

## What to do

Build a bar chart out of text. Each row has a label and one # for each unit. The first function makes one row. The second joins all rows. The third finds the tallest bar.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
