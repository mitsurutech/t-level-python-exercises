# Change types: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.4: Structure, types and changing types](https://mitsurutech.co.uk/resources/t-level/dsd-6-4-types-and-structure)

## What to do

Fill in the five functions. Each one changes data from one type to another.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
