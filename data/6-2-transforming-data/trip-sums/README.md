# Trip sums: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.2: Changing data: manipulate, analyse, process](https://mitsurutech.co.uk/resources/t-level/dsd-6-2-transforming-data)

## What to do

Help Ms Okafor with the trip. Fill in four functions. One adds up the prices. One finds the average. One finds the percentage of students who paid. One keeps the prices below a limit and puts them in order.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
