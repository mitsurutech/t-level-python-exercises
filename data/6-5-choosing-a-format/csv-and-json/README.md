# Csv and json: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.5: Choosing and changing a data format](https://mitsurutech.co.uk/resources/t-level/dsd-6-5-choosing-a-format)

## What to do

Write two functions. The first changes CSV text into a list of dictionaries, the same shape as JSON. Age must be an integer and paid must be a float. The second changes the list back into CSV text.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
