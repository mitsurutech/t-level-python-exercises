# Walk the tree: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.10: Three ways to organise data](https://mitsurutech.co.uk/resources/t-level/dsd-6-10-data-models)

## What to do

The trip is stored as a tree. The trip has buses. Each bus has a list of students. Write three functions that walk down the tree.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
