# Codify comments: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.3: Counted, measured, grouped, and coding words](https://mitsurutech.co.uk/resources/t-level/dsd-6-3-value-kinds-and-coding)

## What to do

A school trip survey has free text comments. Fill in two functions. The first turns one comment into one category: transport, food, activity or other. The second counts how many comments are in each category.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
