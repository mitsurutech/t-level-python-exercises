# Sort the files: Python exercise for T Level Digital Software Development

> **From the lesson:** [6.12: Lakes, warehouses and marts](https://mitsurutech.co.uk/resources/t-level/dsd-6-12-warehouse-lake-mart)

## What to do

A shop chain names its files so you can tell where they belong. Raw files go in the data lake. Files starting with clean_ go in the data warehouse. Files starting with mart_ go in a data mart. Write three functions.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
