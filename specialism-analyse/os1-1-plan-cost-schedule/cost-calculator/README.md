# Cost calculator: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 1.1: Plan the project: time, money and language](https://mitsurutech.co.uk/resources/t-level/dsd-os1-1-plan-cost-schedule)

## What to do

Write three small functions to work out the cost of a project. The first finds the people cost: days multiplied by the day rate. The second adds other costs. The third says if the total fits inside the budget. Use the worked example to check your numbers.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
