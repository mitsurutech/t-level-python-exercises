# Skills checker: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 1.6: Find and fill your own skills gaps](https://mitsurutech.co.uk/resources/t-level/dsd-os1-6-training-needs)

## What to do

Skills are stored in a dictionary: the name and a level from 1 to 5. Write a function that compares what you have with what the project needs. It gives back the skills where your level is lower than the level needed, in alphabetical order. A skill you do not have counts as level 0.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
