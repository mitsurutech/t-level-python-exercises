# Risk scorer: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 2.2: Find and rate the risks](https://mitsurutech.co.uk/resources/t-level/dsd-os2-2-find-and-rate-risks)

## What to do

Write three functions. The first multiplies likelihood and seriousness to give a score. The second turns a score into "low", "medium" or "high". The third finds the name of the worst risk in a list. Use the worked example to check your numbers.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
