# Sprint planner: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 1.3: Agile and Scaled Agile](https://mitsurutech.co.uk/resources/t-level/dsd-os1-3-agile-and-scaled)

## What to do

A team can do 10 points of work in every sprint. A project has 25 points. How many sprints does it need? Write a loop that takes the points away one sprint at a time. The second function says if the team finishes in time.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
