# Source rater: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 3.1: Can you trust that source?](https://mitsurutech.co.uk/resources/t-level/dsd-os3-1-reliable-sources)

## What to do

Turn the checklist into code. Four questions are True or False: is the author known, does it give evidence, do other sources agree, is it recent. Count the True answers. Then give a verdict: 3 or 4 points is "reliable", 2 is "check more", 0 or 1 is "do not trust".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
