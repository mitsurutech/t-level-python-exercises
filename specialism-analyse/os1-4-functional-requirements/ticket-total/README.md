# Ticket total: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 1.4: Functional requirements and secure by design](https://mitsurutech.co.uk/resources/t-level/dsd-os1-4-functional-requirements)

## What to do

Write the function for the cinema ticket app. Follow the three requirements in the comments. R1: the two prices. R2: the group discount. R3: bad input gives back None.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
