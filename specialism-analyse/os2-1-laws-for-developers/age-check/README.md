# Age check: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 2.1: The law and your software](https://mitsurutech.co.uk/resources/t-level/dsd-os2-1-laws-for-developers)

## What to do

A game shop app must check the age of a player. A game has a PEGI rating: 3, 7, 12, 16 or 18. In the UK, a child can agree to the use of their data by an online service on their own from age 13. Write the three functions in the starter.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
