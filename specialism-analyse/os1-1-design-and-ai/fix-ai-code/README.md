# Fix ai code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 1.1: Design the product and check AI code](https://mitsurutech.co.uk/resources/t-level/dsd-os1-1-design-and-ai)

## What to do

An AI tool wrote the three functions in the starter. Each one breaks a requirement. Read the comment above each function, then fix the code.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
