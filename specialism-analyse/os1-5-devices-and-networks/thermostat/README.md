# Thermostat: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 1.5: Smart devices, robots, cloud and 5G](https://mitsurutech.co.uk/resources/t-level/dsd-os1-5-devices-and-networks)

## What to do

Write two small functions for a smart heating system. The first gives back "on" if the room is colder than the target, or "off" if it is the same or warmer. The second works through a list of readings and gives back a list of commands.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
