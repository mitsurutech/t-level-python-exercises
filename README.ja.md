# T Level デジタルソフトウェア開発：スターターコード付きのPythonプログラミング演習

[English](README.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [Español](README.es.md)

デジタルソフトウェア開発の T Level 技術資格（レベル3）で学ぶ生徒のための、無料のPythonプログラミング演習です。214個の課題があり、それぞれにやさしい英語の課題文とスターターコードが付いています。Pearson の仕様書のトピック番号に対応しています。

## 中身

各フォルダーは、T Level デジタルのレッスンにある課題1つです。何をするかを書いた README と、取りかかるためのスターターファイルが入っています。自分のエディターで取り組み、考え方を知りたいときは先にレッスンを読んでください。

## 使い方

1. 下の一覧から課題を選び、そのフォルダーを開きます。
2. README を読み、スターターファイルで作業します。
3. 行き詰まったら、課題からリンクされたレッスンのプレビューを開いてください。考え方を説明しています。

隠しテストと模範解答はここにはありません。課題を出し、採点し、フィードバックできる、完全版のカリキュラムにあります。
