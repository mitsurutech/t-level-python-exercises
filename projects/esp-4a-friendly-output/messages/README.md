# Messages: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 4a: Screens and messages people understand](https://mitsurutech.co.uk/resources/t-level/dsd-esp-4a-friendly-output)

## What to do

Make the booking tool easy to use. normalise_choice cleans a typed answer. format_price shows a price with 2 decimal places and the word pounds. menu_text makes a numbered menu. booking_message gives a clear message for "ok", "closed", "taken" or "bad_court". Read the comments in the starter for what each message must say.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
