# Checker: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 4b: Explain your work to a client](https://mitsurutech.co.uk/resources/t-level/dsd-esp-4b-report-and-present)

## What to do

Write a small tool that checks how easy a text is to read. sentences_of splits text into sentences. average_sentence_length gives the average number of words in a sentence, rounded to 1 decimal place. long_sentences gives the sentences with more than a limit of words.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
