# Risk code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OSP task 1: Sources, risks and the law](https://mitsurutech.co.uk/resources/t-level/dsd-osp-1-sources-risks-law)

## What to do

Write three functions for a risk register. risk_score multiplies likelihood and impact. risk_level gives low for 1 or 2, medium for 3 or 4, and high for 5 or more. worst_risk gives the name of the risk with the highest score, or None for an empty list.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
