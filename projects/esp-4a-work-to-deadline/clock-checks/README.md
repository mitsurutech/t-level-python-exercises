# Clock checks: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 4a: Work well against the clock](https://mitsurutech.co.uk/resources/t-level/dsd-esp-4a-work-to-deadline)

## What to do

Write two functions about the clock. minutes_between gives the minutes from one time to another, for times written like "09:45". finishes_in_time says if you finish by the deadline. Change each time to minutes since midnight first: hours times 60, plus minutes.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
