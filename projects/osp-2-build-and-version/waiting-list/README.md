# Waiting list: Python exercise for T Level Digital Software Development

> **From the lesson:** [OSP task 2: Build, save versions and review code](https://mitsurutech.co.uk/resources/t-level/dsd-osp-2-build-and-version)

## What to do

Task 2 practice. Build two more waiting list functions. join_waiting_list is finished. next_in_line gives the first member waiting for a court and hour, or None. leave_waiting_list removes a member and gives back True or False. Commit after each function if you use Git.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
