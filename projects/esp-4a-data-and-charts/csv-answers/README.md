# Csv answers: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 4a: Data from CSV files and charts](https://mitsurutech.co.uk/resources/t-level/dsd-esp-4a-data-and-charts)

## What to do

This is stage 4a of the Hillside practice project. Answer the manager's two questions with plain Python. The data is CSV text with a header line: member,court,hour. bookings_per_member gives a dictionary of names and counts. busiest_hour gives the hour with the most bookings; if two are equal, give the earlier hour.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
