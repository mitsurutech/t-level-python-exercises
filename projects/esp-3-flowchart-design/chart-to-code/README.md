# Chart to code: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 3: Design the steps with a flowchart](https://mitsurutech.co.uk/resources/t-level/dsd-esp-3-flowchart-design)

## What to do

Turn the flowchart into code. Write check_booking so that it gives back "Closed", "No such court", "Taken" or "OK". The opening hours are 9 to 20 and there are two courts.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
