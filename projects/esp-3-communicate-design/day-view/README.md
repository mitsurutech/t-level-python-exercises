# Day view: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 3: Design so others can build it](https://mitsurutech.co.uk/resources/t-level/dsd-esp-3-communicate-design)

## What to do

Turn the loop flowchart into code. booked_hours lists the booked hours in order. day_lines gives one line for each hour from 9 to 20: "10: Sam" or "9: free". free_hours gives the free hours. Use booked_hours inside free_hours, so the idea is written only once.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
