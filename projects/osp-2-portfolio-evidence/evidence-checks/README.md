# Evidence checks: Python exercise for T Level Digital Software Development

> **From the lesson:** [OSP task 2: Build a portfolio of evidence](https://mitsurutech.co.uk/resources/t-level/dsd-osp-2-portfolio-evidence)

## What to do

Write two small helpers for your portfolio. evidence_name makes a clear file name such as task-2-test-plan.pdf from a task number, a description and a file type. missing_items says which required pieces of evidence you do not have yet.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
