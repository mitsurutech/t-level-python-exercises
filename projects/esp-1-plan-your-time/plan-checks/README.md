# Plan checks: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 1: Plan your time and your risks](https://mitsurutech.co.uk/resources/t-level/dsd-esp-1-plan-your-time)

## What to do

Write four small functions that check a time plan. A plan is a list of jobs, each with a name and minutes, such as ("Build", 120). total_minutes adds the minutes. fits says if the plan is short enough. spare_minutes says how many minutes are left. total_cost gives the cost of the time at a price per hour.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
