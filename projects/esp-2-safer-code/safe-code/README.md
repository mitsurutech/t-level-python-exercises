# Safe code: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 2: Make code safer](https://mitsurutech.co.uk/resources/t-level/dsd-esp-2-safer-code)

## What to do

Make three small functions that protect the Hillside tool. clean_name removes spaces from the start and end of a name and refuses a bad one. mask hides all but the last 4 characters. is_strong_password checks a password is at least 8 characters with a letter and a digit (0 to 9). Read the comments in the starter.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
