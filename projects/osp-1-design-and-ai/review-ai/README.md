# Review ai: Python exercise for T Level Digital Software Development

> **From the lesson:** [OSP task 1: Design the solution and use AI wisely](https://mitsurutech.co.uk/resources/t-level/dsd-osp-1-design-and-ai)

## What to do

Task 1 practice. An AI tool wrote this function. Read it and run the tests. It has two problems. Find them and fix them. Then, in a comment above the function, write one line for each problem.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
