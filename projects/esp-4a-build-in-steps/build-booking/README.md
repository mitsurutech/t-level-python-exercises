# Build booking: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 4a: Build the solution in small steps](https://mitsurutech.co.uk/resources/t-level/dsd-esp-4a-build-in-steps)

## What to do

This is stage 4a of the Hillside practice project. Build book and cancel. is_free is finished for you. Work in small steps: first make book add a booking, then add one check at a time, then write cancel. Run the tests after each step.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
