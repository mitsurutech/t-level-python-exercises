# Ratings: Python exercise for T Level Digital Software Development

> **From the lesson:** [OSP task 3: Gather feedback from real users](https://mitsurutech.co.uk/resources/t-level/dsd-osp-3-gather-feedback)

## What to do

Task 3a practice. Members rate the tool from 1 to 5. Write `average_rating`. It gives the average rounded to 1 decimal place, or 0 for an empty list. Then write `count_ratings`. It gives a dictionary of how many people gave each rating from 1 to 5.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
