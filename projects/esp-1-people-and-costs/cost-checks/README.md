# Cost checks: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 1: People, costs and your reasons](https://mitsurutech.co.uk/resources/t-level/dsd-esp-1-people-and-costs)

## What to do

Write five small functions for a cost plan. An item is (name, kind, amount, price_each). item_cost gives amount times price. total_cost adds every item. cost_by_kind gives the total for each kind. is_affordable compares the total with the budget. weeks_to_pay_back gives whole weeks, rounded up (10.2 weeks becomes 11).

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
