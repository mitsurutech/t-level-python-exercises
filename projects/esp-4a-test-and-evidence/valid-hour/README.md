# Valid hour: Python exercise for T Level Digital Software Development

> **From the lesson:** [ESP tasks 2, 4a: Test your work and keep proof](https://mitsurutech.co.uk/resources/t-level/dsd-esp-4a-test-and-evidence)

## What to do

This is stage 4a of the Hillside practice project. Write valid_hour. It takes what a person typed and gives back the hour as an integer if it is a whole number from 9 to 20. For anything else it gives back None. Think about empty text, words, decimals (like 10.5), numbers below zero and spaces.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
