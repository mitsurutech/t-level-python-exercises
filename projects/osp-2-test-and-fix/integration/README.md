# Integration: Python exercise for T Level Digital Software Development

> **From the lesson:** [OSP task 2: Test, report and fix](https://mitsurutech.co.uk/resources/t-level/dsd-osp-2-test-and-fix)

## What to do

Task 2 practice. The parts of the waiting list each pass their own tests. But cancel_and_promote, which joins them, has two faults. Run the tests, read the messages and find both. Fix the function. Then run all tests again.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
