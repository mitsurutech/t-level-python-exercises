# Checklist: Python exercise for T Level Digital Software Development

> **From the lesson:** [4.1: The laws together, and law across borders](https://mitsurutech.co.uk/resources/t-level/dsd-4-1-laws-together)

## What to do

The team keeps a checklist. It is a dictionary: each law is a key, and the value is True if the team has done the check. Write three functions. The first lists the laws not done, in order of the alphabet. The second says if the team is ready to launch: every check done. The third gives back text such as "2 of 4 checks done".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
