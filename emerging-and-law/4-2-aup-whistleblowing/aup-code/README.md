# Aup code: Python exercise for T Level Digital Software Development

> **From the lesson:** [4.2: Acceptable use policies and speaking up](https://mitsurutech.co.uk/resources/t-level/dsd-4-2-aup-whistleblowing)

## What to do

Make the rules of an AUP work in code. The first function says if a website is allowed: it is not on the blocked list. The second finds banned words in a message and gives them back in order. Ignore capital letters. The third says what the sanction is for a number of strikes.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
