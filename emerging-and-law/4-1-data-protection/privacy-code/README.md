# Privacy code: Python exercise for T Level Digital Software Development

> **From the lesson:** [4.1: Data protection law and your data](https://mitsurutech.co.uk/resources/t-level/dsd-4-1-data-protection)

## What to do

Write three small functions that follow the principles.
1. Keep only the fields a form needs: data minimisation.
2. Find records that have not been used for more than a set number of years: limited storage.
3. Hide part of an email address: security.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
