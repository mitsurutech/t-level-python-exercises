# Access code: Python exercise for T Level Digital Software Development

> **From the lesson:** [4.1: The Computer Misuse Act](https://mitsurutech.co.uk/resources/t-level/dsd-4-1-computer-misuse)

## What to do

Authorised means "allowed by the owner". The permissions are a dictionary: each name has a list of the things that person may use. Write three functions to check permission.
1. Say if a user may use a resource.
2. Give back a message.
3. Count how many attempts were not allowed.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
