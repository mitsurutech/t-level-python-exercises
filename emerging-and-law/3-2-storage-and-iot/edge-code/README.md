# Edge code: Python exercise for T Level Digital Software Development

> **From the lesson:** [3.2: Storage, quantum computers and the Internet of Things](https://mitsurutech.co.uk/resources/t-level/dsd-3-2-storage-and-iot)

## What to do

Fill in three functions.
1. Work out how many photos fit on a phone. One GB is 1000 MB. Use whole numbers.
2. Keep only the temperature readings that are too low or too high. This is edge computing: only unusual readings are sent.
3. Give back text such as "Sent 3 of 4 readings".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
