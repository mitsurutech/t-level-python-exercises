# Make robust: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.10: Robust code](https://mitsurutech.co.uk/resources/t-level/dsd-2-10-robust-code)

## What to do

Make four functions robust. Use try and except.

1. `safe_int(text)` gives back a whole number, or None if the text is not one.
2. `safe_divide(a, b)` gives back the answer, or the text "Cannot divide by zero".
3. `read_first_line(filename)` gives back the first line of a file, or "File not found: " and the file name.
4. `average_of_text(values)` ignores anything that is not a whole number and gives back the average of the rest. Tip: use your safe_int.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
