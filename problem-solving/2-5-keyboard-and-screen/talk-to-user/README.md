# Talk to user: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.5: Input from the keyboard, output to the screen](https://mitsurutech.co.uk/resources/t-level/dsd-2-5-keyboard-and-screen)

## What to do

Write four functions. The test checks the prompt exactly, with one space at the end. ask_name asks "What is your name? " with input() and gives back the text "Hello, " and the name, for example Hello, Sam. show_total prints Total: and the number, for example Total: 7. ask_age_next_year asks "Age? " and gives back the age plus 1 as a whole number. safe_int changes text to a whole number, or gives back None if it cannot. The tests type for you.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
