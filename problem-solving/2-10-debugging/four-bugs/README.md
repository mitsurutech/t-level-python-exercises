# Four bugs: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.10: Finding and fixing bugs](https://mitsurutech.co.uk/resources/t-level/dsd-2-10-debugging)

## What to do

Four functions each have a bug. Read the comments, find the cause and fix it.

1. `average` should divide by the right count.
2. `longest_word` should give back the longest word.
3. `count_vowels` should count capital letters too.
4. `is_leap_year` is missing one rule. `year % 4 == 0` asks if a year is divisible by 4.

Then do the next one.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
