# Build checks: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.8: Validation: checking input](https://mitsurutech.co.uk/resources/t-level/dsd-2-8-validation-checks)

## What to do

Build four checks and one loop. `present(text)` is True if something was typed. Spaces alone do not count. `long_enough(password)` is True for 8 to 20 characters. `age_ok(text)` is True if the text is a whole number from 0 to 120: check the type first. `email_ok(email)` is True if there is exactly one @ and a dot after it. `get_age()` asks with `input` until the age is valid. After each bad try it prints exactly: Please type a whole number from 0 to 120.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
