# Build b: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.9: Judging a solution](https://mitsurutech.co.uk/resources/t-level/dsd-2-9-judging-solutions)

## What to do

Build the better solution. The constants are at the top. `order_total(items)` adds up the prices of a list of items. If the total is below `FREE_DELIVERY_FROM`, it adds `DELIVERY_FEE`. A total exactly equal to it pays no fee. Use the constants and do not type their numbers again. `cheapest_item(prices)` gives back the name of the cheapest item. `price_label(amount)` gives back text such as "£2.50", with `format`.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
