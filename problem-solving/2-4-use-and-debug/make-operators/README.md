# Make operators: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.4: Read, write and fix code with operators](https://mitsurutech.co.uk/resources/t-level/dsd-2-4-use-and-debug)

## What to do

Write two functions with operators. ticket_price gives 0 under age 5, 5 for students and anyone under 16, and 10 for everyone else. is_leap_year follows the leap year rule in the comments. Use and, or and the modulus operator.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
