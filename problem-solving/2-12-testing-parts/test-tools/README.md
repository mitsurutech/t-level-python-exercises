# Test tools: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.12: Testing parts, then the whole](https://mitsurutech.co.uk/resources/t-level/dsd-2-12-testing-parts)

## What to do

Build three small testing tools.

1. `boundary_values(low, high)` gives back a list of the four boundary values: one below the lowest, the lowest, the highest and one above the highest.
2. `is_boundary(value, low, high)` gives back True if a value is one of those four, and False if not.
3. `unit_result(actual, expected)` gives back "PASS" if the two are equal and "FAIL" if they are different.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
