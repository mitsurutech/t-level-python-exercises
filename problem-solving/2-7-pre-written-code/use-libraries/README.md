# Use libraries: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.7: Using code that others wrote](https://mitsurutech.co.uk/resources/t-level/dsd-2-7-pre-written-code)

## What to do

Use pre-written code to finish four functions. `pages_needed(items, per_page)` gives back how many pages are needed: use `math.ceil`. `circle_area(radius)` uses `math.pi`. `cheapest(prices)` uses `min`. `lucky_dip(numbers, k)` picks k different numbers from the list: use `random.sample`. The imports are already at the top.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
