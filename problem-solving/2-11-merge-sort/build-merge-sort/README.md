# Build merge sort: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.11: Merge sort](https://mitsurutech.co.uk/resources/t-level/dsd-2-11-merge-sort)

## What to do

Build the parts of merge sort.

1. `middle_point(items)` gives back where to split a list: half the number of items, using `//`. So 5 items split at 2.
2. `merge(left, right)` joins two sorted lists into one sorted list. Take the smaller front item each time. When one list runs out, add what is left of the other.
3. `is_sorted(items)` gives back True if a list is in order, and False if not.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
