# Steps to python: Python exercise for T Level Digital Software Development

> **From the lesson:** [1.2: One algorithm, three ways to write it](https://mitsurutech.co.uk/resources/t-level/dsd-1-2-written-and-code)

## What to do

Each function has written steps in its comments. Turn the steps into Python.

1. bus_fare uses selection: under 5 pays 0, under 16 pays 1, everyone else pays 2.
2. countdown_text uses iteration: countdown_text(3) gives 3 2 1 Go!
3. welcome uses sequence.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
