# Date functions: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.7: Working with dates and times](https://mitsurutech.co.uk/resources/t-level/dsd-2-7-dates-and-times)

## What to do

Finish four functions.

1. show_date gives back text like 25/12/2026 from a date.
2. read_date makes a date from that kind of text, or gives back None when the text is not a real date. Use try and except.
3. day_name gives back the day of the week, such as Friday.
4. is_weekend gives back True if a date text is a Saturday or a Sunday, and False if not.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
