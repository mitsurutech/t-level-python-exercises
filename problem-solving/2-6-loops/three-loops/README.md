# Three loops: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.6: Repeating with loops](https://mitsurutech.co.uk/resources/t-level/dsd-2-6-loops)

## What to do

Write three functions with loops.

1. `times_table(n)` gives back a list of the first 12 answers in the n times table. Use a for loop.
2. `add_up(numbers)` gives back the total of the list. Use a for loop. Do not use `sum()`.
3. `weeks_to_save(goal, per_week)` gives back how many weeks it takes to reach the goal. Use a while loop.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
