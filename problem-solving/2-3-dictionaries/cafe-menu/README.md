# Cafe menu: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.3: Dictionaries: look it up by name](https://mitsurutech.co.uk/resources/t-level/dsd-2-3-dictionaries)

## What to do

A cafe keeps its prices in a dictionary. Item names are keys, prices are values.

1. price_of gives back the price of one item.
2. add_price adds an item and its price, and gives back the menu.
3. can_order gives back True if the item is on the menu, and False if not.
4. bill adds up the price of every item in a list called order. An item can be in the order twice.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
