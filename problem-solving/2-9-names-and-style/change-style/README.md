# Change style: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.9: Names and code style](https://mitsurutech.co.uk/resources/t-level/dsd-2-9-names-and-style)

## What to do

Write three functions about naming styles. `to_snake_case(name)` changes camelCase into snake_case. `to_camel_case(name)` changes snake_case into camelCase. `is_snake_case(name)` is True when the name has only small letters, digits and underscores, is not empty and does not start with a digit.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
