# Fix the order: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.9: Order, speed and memory](https://mitsurutech.co.uk/resources/t-level/dsd-2-9-order-and-efficiency)

## What to do

Two functions have an order bug: `average_of_three` and `to_fahrenheit`. Fix them with brackets or by changing the calculation. Then finish three more. `safe_share` shares a bill and must not divide by 0. `price_of` looks an item up in the dictionary and gives back 0.0 if it is missing. `first_full_marks` gives back the position of the first score of 100, and stops as soon as it finds it.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
