# Use patterns: Python exercise for T Level Digital Software Development

> **From the lesson:** [1.1: Pattern recognition](https://mitsurutech.co.uk/resources/t-level/dsd-1-1-pattern-recognition)

## What to do

Each function uses a pattern.

1. next_number gives the next number when the step is the same each time. For 5 and 8 it gives 11.
2. next_week_savings is the same problem with money. Reuse your idea from step 1.
3. is_going_up says True if three numbers show a rising trend: each one is bigger than the one before.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
