# Paint room: Python exercise for T Level Digital Software Development

> **From the lesson:** [1.3: Top-down, bottom-up and modules](https://mitsurutech.co.uk/resources/t-level/dsd-1-3-top-down-bottom-up)

## What to do

Build up from a small tool. area is built for you. Write wall_cost, which gives the cost to paint one wall: area times the price of one square metre. Then write room_cost for a room with four walls. Two walls are length by height. Two are width by height. Use wall_cost again.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
