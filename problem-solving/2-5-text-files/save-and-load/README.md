# Save and load: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.5: Saving and loading with text files](https://mitsurutech.co.uk/resources/t-level/dsd-2-5-text-files)

## What to do

Write four functions that use text files. save_scores opens a file for writing, writes each score on its own line, and closes it. load_scores reads the lines and gives back a list of whole numbers. count_lines says how many lines a file has. parse_line turns Sam,16 into the list Sam and 16, where 16 is a whole number.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
