# Barcode checks: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.8: The check digit](https://mitsurutech.co.uk/resources/t-level/dsd-2-8-check-digits)

## What to do

Write two functions about check digits. `simple_check_digit(digits)` adds the digits and gives back the digit that makes the total end in 0. `is_valid_code(code)` is True only for a good code. It has at least 2 characters and they are all digits. The last digit is the check digit of the digits before it. Check the type first.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
