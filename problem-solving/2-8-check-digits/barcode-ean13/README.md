# Barcode ean13: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.8: The check digit](https://mitsurutech.co.uk/resources/t-level/dsd-2-8-check-digits)

## What to do

Extra, not in the exam. Write two functions for a real 13 digit shop barcode. `check_digit(first12)` uses the weights 1, 3, 1, 3 and gives back a whole number. `is_valid_barcode(code)` is True only for a 13 digit code whose last digit is right. Check the length and the type first.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
