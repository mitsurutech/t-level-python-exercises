# Four subroutines: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.7: Functions and procedures](https://mitsurutech.co.uk/resources/t-level/dsd-2-7-functions-procedures)

## What to do

Finish four subroutines. `area(width, height)` is a function: give back width times height. `welcome(name)` is a procedure: print exactly `Welcome, Sam!` when the name is Sam. There is a comma and a space after Welcome, and no space before the exclamation mark. Return nothing. `bigger(a, b)` is a function: give back the larger number. `lucky_number()` is a function with no parameters: give back 7.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
