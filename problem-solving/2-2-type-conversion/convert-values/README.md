# Convert values: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.2: Changing one data type to another](https://mitsurutech.co.uk/resources/t-level/dsd-2-2-type-conversion)

## What to do

Use int(), float(), str() and bool() to finish four functions. total_price gets a price and a quantity as text and gives back a float. next_age gets the age as text and gives back the age next year as an integer. score_label gives text like Score: 7. has_name gives True if the name is not empty.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
