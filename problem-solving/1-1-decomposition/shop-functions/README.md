# Shop functions: Python exercise for T Level Digital Software Development

> **From the lesson:** [1.1: Decomposition: break it down](https://mitsurutech.co.uk/resources/t-level/dsd-1-1-decomposition)

## What to do

A small shop makes a receipt. Break the job into three small functions.

1. item_cost gives price times quantity.
2. delivery_charge gives 0 for 20 pounds or more, and 3 for less.
3. receipt_line gives text like 2 x Cola = 3.0.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
