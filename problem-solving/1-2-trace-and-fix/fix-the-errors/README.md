# Fix the errors: Python exercise for T Level Digital Software Development

> **From the lesson:** [1.2: Trace it, find the error, fix it](https://mitsurutech.co.uk/resources/t-level/dsd-1-2-trace-and-fix)

## What to do

Three functions each have one logic error. Find it and fix it.

1. average should add two numbers and divide by 2.
2. is_adult should say if somebody is 18 or over.
3. total_to should add the whole numbers from 1 up to n.

If you are stuck, write a trace table on paper.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
