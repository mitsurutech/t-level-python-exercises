# Bus fare: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.1: Standard data types](https://mitsurutech.co.uk/resources/t-level/dsd-2-1-standard-data-types)

## What to do

A bus ticket costs 2.50. Fill in the three functions. The first finds the cost for a group. It must give back a float. The second says if a person is a child. Under 16 is a child. It gives back True or False. The third joins strings to make a label.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
