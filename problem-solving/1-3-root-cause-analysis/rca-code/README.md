# Rca code: Python exercise for T Level Digital Software Development

> **From the lesson:** [1.3: Root cause analysis](https://mitsurutech.co.uk/resources/t-level/dsd-1-3-root-cause-analysis)

## What to do

Write three small functions for a support team. risk_score multiplies how bad (1 to 5) by how likely (1 to 5). log_entry gives text like Problem: App crashed. Cause: No memory left. what_next says close if fixed, escalate if it is not fixed and cannot be fixed here, and keep working if not.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
