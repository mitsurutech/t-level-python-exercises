# Text tools: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.5: Cleaning and checking typed text](https://mitsurutech.co.uk/resources/t-level/dsd-2-5-handling-text)

## What to do

Write six functions that clean and check text. shout removes spaces from both ends and makes capitals. is_valid_age is True when the text is only digits. first_word gives the first word of a sentence. clean_phone takes every space out of a phone number. username_ok is True for letters and digits only, at least 4 characters long. next_letter gives the next letter of the alphabet, using ord() and chr().

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
