# Leaderboard: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.3: Build and debug with lists and dictionaries](https://mitsurutech.co.uk/resources/t-level/dsd-2-3-build-and-debug)

## What to do

Build three tools for a leaderboard.

1. best_score gives back the biggest score.
2. count_passes counts the scores that are the pass mark or higher.
3. average adds the scores up and divides by how many there are.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
