# Fix structures: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.3: Build and debug with lists and dictionaries](https://mitsurutech.co.uk/resources/t-level/dsd-2-3-build-and-debug)

## What to do

Four functions each have one bug. Find it and fix it.

1. last_item should give back the last item.
2. sorted_scores should give back the scores, lowest first.
3. safe_price should give back 0 for an item that is not on the menu.
4. first_item should give back the first item.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
