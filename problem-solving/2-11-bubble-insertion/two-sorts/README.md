# Two sorts: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.11: Bubble sort and insertion sort](https://mitsurutech.co.uk/resources/t-level/dsd-2-11-bubble-insertion)

## What to do

Write four functions. Do not change the list you are given: start with an empty list called `result` and use `append` to copy each item into it.

1. `one_bubble_pass(items)` does one pass of bubble sort and gives back the new list.
2. `bubble_sort(items)` gives back a new sorted list.
3. `insertion_sort(items)` does the same with insertion sort.
4. `bubble_passes(items)` counts the passes bubble sort makes. The last pass, with no swaps, counts too. So `[5, 3, 8, 1]` needs 4 passes, and a list already in order needs 1.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
