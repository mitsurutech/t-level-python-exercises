# Test scripts: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.12: More testing methods and automation](https://mitsurutech.co.uk/resources/t-level/dsd-2-12-more-methods-automation)

## What to do

Write four small automation scripts.

1. `count_passes(actual, expected)` compares two lists and gives back how many answers match.
2. `regression_check(old_answers, new_answers)` gives back a list of the positions where an answer has changed.
3. `fast_enough(seconds_taken, limit_seconds)` gives back True if the time was under the limit. Exactly on the limit is not fast enough.
4. `load_report(replies)` counts how many users got "ok".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
