# Pizza shop: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.2: Variables and constants](https://mitsurutech.co.uk/resources/t-level/dsd-2-2-variables-constants)

## What to do

A pizza shop sells pizzas for 8 pounds each. Delivery costs 2 pounds for the whole order. First, set the two constants at the top. Then write order_total, change_due and order_text. order_text(Sam, 3) gives Sam ordered 3 pizzas.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
