# Fare calculator: Python exercise for T Level Digital Software Development

> **From the lesson:** [1.1: Abstraction: keep what matters](https://mitsurutech.co.uk/resources/t-level/dsd-1-1-abstraction)

## What to do

Use abstraction to build a bus fare calculator. The child fare is 1.0. The adult fare is 2.0. A child is under 16.

1. Set the two constants first.
2. fare_for_one gives the fare for one journey.
3. trip_cost multiplies the fare by the number of journeys.
4. describe_trip gives text like 3 journeys cost 6.0.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
