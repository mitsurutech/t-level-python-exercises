# Fix and write: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.6: Read, write and fix choices and loops](https://mitsurutech.co.uk/resources/t-level/dsd-2-6-trace-and-debug)

## What to do

Three functions have a bug each, and one is for you to write. Read the comments.

1. Fix `is_teenager`.
2. Fix `count_evens`. The test `number % 2 == 0` asks if a number is even. The sign `%` gives the remainder after dividing: 6 % 2 is 0 and 7 % 2 is 1.
3. Fix `sum_to`.
4. Write `countdown` with a while loop.

Use a trace table on paper if you get stuck.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
