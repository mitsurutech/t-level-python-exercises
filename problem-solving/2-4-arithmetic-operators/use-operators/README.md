# Use operators: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.4: Arithmetic operators](https://mitsurutech.co.uk/resources/t-level/dsd-2-4-arithmetic-operators)

## What to do

Use the right operator in four functions. hours_and_minutes turns 135 into 2 hours 15 minutes. square multiplies a number by itself using the power operator. each_person_pays gives the whole pounds each person pays when a bill is shared. left_over gives the pounds that remain.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
