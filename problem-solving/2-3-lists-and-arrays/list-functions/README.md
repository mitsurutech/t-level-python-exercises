# List functions: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.3: Lists and arrays](https://mitsurutech.co.uk/resources/t-level/dsd-2-3-lists-and-arrays)

## What to do

Write four small functions that work on a list.

1. second_item gives back the item at index 1.
2. add_and_count adds an item to the end and gives back how many items there are now.
3. remove_item takes an item out if it is there, and gives back the list.
4. has_item gives back True if the item is in the list, and False if not.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
