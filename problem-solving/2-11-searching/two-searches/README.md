# Two searches: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.11: Linear and binary search](https://mitsurutech.co.uk/resources/t-level/dsd-2-11-searching)

## What to do

Write two searches.

1. `linear_search(items, target)` looks at the items one by one. It gives back the position of the first match, or -1.
2. `binary_search(items, target)` works on a sorted list. It looks at the middle item and keeps one half. It gives back the position, or -1.

One test counts how many items binary search reads in a list of 1000. Up to 60 reads is allowed. A linear search would read 1000, so it fails that test.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
