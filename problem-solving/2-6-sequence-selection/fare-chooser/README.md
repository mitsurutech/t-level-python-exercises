# Fare chooser: Python exercise for T Level Digital Software Development

> **From the lesson:** [2.6: Sequence and selection](https://mitsurutech.co.uk/resources/t-level/dsd-2-6-sequence-selection)

## What to do

Finish two functions.

1. `fare(age)` gives back the price for an age: 0.0 under 5, 1.0 under 16, 1.5 for 65 or over, and 2.5 for everyone else. Use if, elif and else.
2. `day_type(day)` uses match case: "Sat" and "Sun" give back "weekend". Any other day gives back "weekday".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
