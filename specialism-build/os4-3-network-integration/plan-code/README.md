# Plan code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 4.3: Network integration points](https://mitsurutech.co.uk/resources/t-level/dsd-os4-3-network-integration)

## What to do

A game has jobs. For each job you know two facts: does it need data from other players, and must the result be trusted? Write three functions. The first says "local" or "remote" for one job. The second makes a plan for all jobs. The third counts the remote jobs.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
