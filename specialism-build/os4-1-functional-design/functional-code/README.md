# Functional code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 4.1: Functional design](https://mitsurutech.co.uk/resources/t-level/dsd-os4-1-functional-design)

## What to do

Finish five small functions. Each one uses an idea from this lesson: a higher-order function, a closure, recursion, a lambda and currying. Read the comment in each one.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
