# Settings: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.1: Twelve factors, part one](https://mitsurutech.co.uk/resources/t-level/dsd-os6-1-twelve-factor-a)

## What to do

Write the code that reads the settings, as a twelve-factor app should. read_settings takes the environment as a dictionary. It gives back the port, the debug flag and the database address. A missing database address is an error. missing_dependencies finds packages the code uses but nobody wrote down.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
