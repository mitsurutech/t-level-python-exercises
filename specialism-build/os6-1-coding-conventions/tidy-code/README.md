# Tidy code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.1: Coding conventions](https://mitsurutech.co.uk/resources/t-level/dsd-os6-1-coding-conventions)

## What to do

The starter code works but is hard to read. Rewrite it with good names, a docstring in every function, and four spaces of indentation. Then add format_report, which must use average_mark.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
