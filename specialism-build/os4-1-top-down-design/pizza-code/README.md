# Pizza code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 4.1: Top-down design and data flow](https://mitsurutech.co.uk/resources/t-level/dsd-os4-1-top-down-design)

## What to do

Build the three functions from the data flow diagram. Food goes in and a total comes out. The total goes into the delivery job. Both numbers go into the receipt job.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
