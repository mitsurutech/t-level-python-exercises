# Db code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.1: Files and data on a server](https://mitsurutech.co.uk/resources/t-level/dsd-os6-1-files-and-data)

## What to do

Now keep the scores in a database. Use sqlite3 and ? placeholders. Add, change and delete a player. The tests try a name with a quote mark in it.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
