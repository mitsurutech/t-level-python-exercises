# Api code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.3: Connecting to data with an API](https://mitsurutech.co.uk/resources/t-level/dsd-os6-3-apis)

## What to do

A game service sends scores as JSON text. Finish four functions. build_url makes the address of a request. top_player finds the winner. score_lines makes lines to show. with_key adds an API key to an address.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
