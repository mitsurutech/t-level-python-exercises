# Oop code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 4.1: Object-oriented design](https://mitsurutech.co.uk/resources/t-level/dsd-os4-1-oop-design)

## What to do

Finish the Character class. It keeps a name and health. take_damage lowers the health, but never below 0. is_alive says if health is above 0. speak gives back text. Then finish Zombie. A Zombie is a Character, but it says Grr.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
