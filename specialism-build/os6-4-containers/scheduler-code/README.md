# Scheduler code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.4: Containers and schedulers](https://mitsurutech.co.uk/resources/t-level/dsd-os6-4-containers)

## What to do

Write the four helper functions for a tiny scheduler. containers_to_change says how many copies to start or stop. failed_containers finds the failed ones to restart. copies_needed works out how many copies the work needs, rounding up. container_name makes a name such as web-2.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
