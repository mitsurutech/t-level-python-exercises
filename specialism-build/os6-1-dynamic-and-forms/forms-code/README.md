# Forms code: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.1: Dynamic pages, forms and cookies](https://mitsurutech.co.uk/resources/t-level/dsd-os6-1-dynamic-and-forms)

## What to do

Write the four parts of a small web back end. build_page makes safe HTML. handle_form checks form data. parse_cookie reads a Cookie header. make_cookie builds one. Read the comments.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
