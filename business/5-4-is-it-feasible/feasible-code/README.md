# Feasible code: Python exercise for T Level Digital Software Development

> **From the lesson:** [5.4: Is the project feasible?](https://mitsurutech.co.uk/resources/t-level/dsd-5-4-is-it-feasible)

## What to do

Write three functions to help decide if a project is feasible. The first works out how much is saved in all over some years. The second says if the cost is inside the budget. The third says if a project is feasible: it must meet all three limits, which are money, time and people.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
