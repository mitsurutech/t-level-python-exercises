# Sales code: Python exercise for T Level Digital Software Development

> **From the lesson:** [5.2: Digital systems for sales, design, people and operations](https://mitsurutech.co.uk/resources/t-level/dsd-5-2-sales-and-operations)

## What to do

This is analytics in a small way. The first function counts how many times a product was sold. The second finds out if a customer ordered more than once: customer retention. The third makes a personal suggestion from the last item bought.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
