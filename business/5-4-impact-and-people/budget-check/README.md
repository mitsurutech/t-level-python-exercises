# Budget check: Python exercise for T Level Digital Software Development

> **From the lesson:** [5.4: Impact, resources and telling people](https://mitsurutech.co.uk/resources/t-level/dsd-5-4-impact-and-people)

## What to do

Sam has a list of costs in pounds and a budget. Write three functions. total_cost adds the costs. within_budget gives True if the total is no more than the budget. money_left gives the budget minus the total. It can be below zero.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
