# Money code: Python exercise for T Level Digital Software Development

> **From the lesson:** [5.2: Digital systems for managers, stock and money](https://mitsurutech.co.uk/resources/t-level/dsd-5-2-management-and-money)

## What to do

Write three small functions for a cafe. The first lists the items to re-order: those with less than a set minimum left. The second works out profit: all income minus all costs. The third gives back a report line such as "May: profit 300".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
