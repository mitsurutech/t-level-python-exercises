# Cab code: Python exercise for T Level Digital Software Development

> **From the lesson:** [5.4: Planning a change: the change board and goals](https://mitsurutech.co.uk/resources/t-level/dsd-5-4-planning-a-change)

## What to do

You are the change advisory board. Each request is a list of three things: name, urgency and cost. For example ["fix login", 3, 200]. Urgency 3 is the most urgent. First, write a function that finds the most urgent request. Second, go through the requests in the order given and approve each one whose cost fits in the budget that is left. Third, add up the cost of the chosen requests.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
