# Switch code: Python exercise for T Level Digital Software Development

> **From the lesson:** [5.4: Testing, rolling out and going back](https://mitsurutech.co.uk/resources/t-level/dsd-5-4-testing-and-rollout)

## What to do

This task is about running the old and new systems in parallel. The first function finds the places where the old and the new results are different. The second says if the new system is ready to switch on: only a few differences are allowed. The third is a rollback helper: it finds the newest backup made on or before a day. If there is none, give back None.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
