# T Level Digital Software Development: Python coding exercises with starter code

[English](README.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [Español](README.es.md)

Free Python coding exercises for students on the T Level Technical Qualification in Digital Software Development (Level 3): 214 tasks, each with a plain-English brief and starter code, keyed to the topic numbers of Pearson’s specification.

## What is in it

Every folder is one task from our T Level Digital lessons. It holds a README that says what to do, and the starter files to work from. Use your own editor, and read the lesson first if you want the idea explained.

## How to use it

1. Pick a task from the list below and open its folder.
2. Read its README, then work in the starter files.
3. Stuck? Open the lesson preview linked from the task, which explains the idea.

The hidden tests and the model answers are not here. They stay in the full curriculum, where a teacher can set a task, mark it and give feedback.
