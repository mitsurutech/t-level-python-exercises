# Audit: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.6: Updates, replacement and hardening](https://mitsurutech.co.uk/resources/t-level/dsd-7-6-updates-and-hardening)

## What to do

Write two functions for a small security audit. unneeded_ports(open_ports, needed_ports) gives back the open ports the system does not need, in order from the smallest. needs_patch(installed_version, fixed_version) gives back True if the installed version is older than the version that fixed the weakness.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
