# Who manages: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.5: IaaS, PaaS and SaaS](https://mitsurutech.co.uk/resources/t-level/dsd-7-5-iaas-paas-saas)

## What to do

Turn the table into code. Fill in CLIENT_MANAGES: for each model, the list of layers the client manages. Then write who_manages(model, layer). It gives back "client" or "provider". The models are "iaas", "paas" and "saas". Look at the table in the lesson.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
