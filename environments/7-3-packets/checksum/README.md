# Checksum: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.3: Data packets](https://mitsurutech.co.uk/resources/t-level/dsd-7-3-packets)

## What to do

Write two functions. checksum(text) adds up the code of every character and gives back the total. In Python, ord("A") gives the code of a character, 65. is_damaged(text, check) gives back True when the text no longer matches the check number it came with.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
