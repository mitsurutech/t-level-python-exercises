# Small checksum: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.3: Data packets](https://mitsurutech.co.uk/resources/t-level/dsd-7-3-packets)

## What to do

Write the function small_checksum(text). It adds up the code of every character, like checksum. Then it gives back the remainder after dividing the total by 256. The symbol for the remainder is %.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
