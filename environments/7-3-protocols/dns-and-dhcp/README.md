# Dns and dhcp: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.3: Common network protocols](https://mitsurutech.co.uk/resources/t-level/dsd-7-3-protocols)

## What to do

Write a tiny DNS and a tiny DHCP. POOL is a list of addresses that can be given out. dns_lookup(name) gives back the address for a name from the table, or "not found". dhcp_lease(leased) gives back the first address in POOL that is not in the list leased (leased means already given out). If none is left, it gives back "no address left".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
