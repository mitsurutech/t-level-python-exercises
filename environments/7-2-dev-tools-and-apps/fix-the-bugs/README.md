# Fix the bugs: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.2: Developer tools and everyday apps](https://mitsurutech.co.uk/resources/t-level/dsd-7-2-dev-tools-and-apps)

## What to do

Two functions have a bug. Find each bug and fix it. The first function should give the average of two numbers. The second should give the total of a list of prices. Read the code one line at a time. Remember: the computer does the part in brackets first.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
