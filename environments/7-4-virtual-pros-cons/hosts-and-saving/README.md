# Hosts and saving: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.4: Virtual environments: good and bad](https://mitsurutech.co.uk/resources/t-level/dsd-7-4-virtual-pros-cons)

## What to do

Write two functions.

1. hosts_needed(vms, vms_per_host) gives back how many hosts you need. If some VMs are left over, you need one more host. For example, 21 VMs at 5 for each host: 21 // 5 is 4, and 21 % 5 is 1 left over. So you need 5 hosts.
2. yearly_saving(old_count, old_cost, new_count, new_cost) gives back the money saved in a year: the old total take away the new total.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
