# Headers: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.3: The OSI and TCP/IP models](https://mitsurutech.co.uk/resources/t-level/dsd-7-3-osi-and-tcpip)

## What to do

A message goes down the layers. Each layer adds a label (a header) at the front.

1. Write add_headers. It adds "[TCP]", then "[IP]", then "[Frame]". Each new label goes at the very front.
2. Write remove_headers. The other computer takes the labels off in the opposite order.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
