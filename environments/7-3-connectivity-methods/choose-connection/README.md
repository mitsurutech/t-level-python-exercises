# Choose connection: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.3: Wired and wireless connections](https://mitsurutech.co.uk/resources/t-level/dsd-7-3-connectivity-methods)

## What to do

Write the function choose_connection. It gets the distance in metres and True or False for a moving device. A moving device uses "wireless". A fixed device up to 100 metres away uses "ethernet". A fixed device further than 100 metres uses "fibre". These are simple rules for this exercise.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
