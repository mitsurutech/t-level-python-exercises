# Downtime sums: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.6: Why resilient systems matter](https://mitsurutech.co.uk/resources/t-level/dsd-7-6-why-resilience)

## What to do

Write two functions. downtime_cost(minutes, pounds_per_minute) gives back the money lost while a system is down. meets_target(downtime_minutes, allowed_minutes) gives back True if the downtime is within the target. Equal to the target is fine.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
