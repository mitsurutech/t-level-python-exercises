# Download time: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.3: Bandwidth and latency](https://mitsurutech.co.uk/resources/t-level/dsd-7-3-bandwidth-latency)

## What to do

Write a function. download_seconds(size_mb, speed_mbps) gives back the seconds a download takes. Remember that 1 byte is 8 bits.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
