# Best app: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.2: Everyday applications in detail](https://mitsurutech.co.uk/resources/t-level/dsd-7-2-office-apps)

## What to do

Write the function best_app. It gets a job as text and gives back the best application: "word processor", "spreadsheet", "database", "email" or "project management". The comments in the starter list the words to look for. For any other job, give back "unknown".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
