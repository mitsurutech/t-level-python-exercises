# Defragment: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.2: Utility software](https://mitsurutech.co.uk/resources/t-level/dsd-7-2-utilities)

## What to do

Write the function defragment. It gets a list of blocks. A letter is a block of a file. A dash is free space.

1. Give back a new list.
2. Put the blocks of each file together, in alphabet order. Use sort().
3. Put all the free space at the end.

For example, ["A", "B", "A", "B"] becomes ["A", "A", "B", "B"].

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
