# Run order: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.2: Types of operating system](https://mitsurutech.co.uk/resources/t-level/dsd-7-2-operating-systems)

## What to do

A multitasking system gives each task a short turn, called a slice. Write the function run_order. It gets two lists: the names of the tasks, and how many slices each one needs. Each round, every task that is not finished gets one slice. Give back a list with the name of the task for each slice, in the order they run. For example, run_order(["music", "chat"], [2, 1]) gives ["music", "chat", "music"].

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
