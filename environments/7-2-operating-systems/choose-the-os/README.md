# Choose the os: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.2: Types of operating system](https://mitsurutech.co.uk/resources/t-level/dsd-7-2-operating-systems)

## What to do

Write the function choose_os. It gets a short phrase that says what a computer needs. Give back the kind of operating system that fits: batch, multitasking, real-time, network or mobile. The starter lists the five phrases. Use if, elif and else. Any other phrase gives "unknown".

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
