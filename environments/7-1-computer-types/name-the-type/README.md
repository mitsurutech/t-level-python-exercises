# Name the type: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.1: Types of computer](https://mitsurutech.co.uk/resources/t-level/dsd-7-1-computer-types)

## What to do

The flowchart above asks three questions. Turn it into a function. The function gets three answers, each True or False: is it built inside another machine, does it serve other computers, and do you carry it. Follow the diagram. Give back "embedded device", "server", "mobile device" or "personal computer". Ask the questions in the same order as the diagram.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
