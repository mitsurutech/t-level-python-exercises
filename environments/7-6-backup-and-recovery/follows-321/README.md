# Follows 321: Python exercise for T Level Digital Software Development

> **From the lesson:** [7.6: Backups, recovery sites and procedures](https://mitsurutech.co.uk/resources/t-level/dsd-7-6-backup-and-recovery)

## What to do

Write a function. follows_321(copies, media_types, offsite_copies) gives back True if there are at least 3 copies. They must be on at least 2 kinds of storage. At least 1 copy must be offsite. Otherwise it gives back False.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
