# Triad checks: Python exercise for T Level Digital Software Development

> **From the lesson:** [8.4: The CIA triad](https://mitsurutech.co.uk/resources/t-level/dsd-8-4-cia-triad)

## What to do

Fill in three functions. The first says which goal an event breaks. The second says if text is unchanged, by comparing it with a saved copy. The third works out how many minutes a system was available.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
