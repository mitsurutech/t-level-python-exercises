# Phish checker: Python exercise for T Level Digital Software Development

> **From the lesson:** [8.2: Tricks that fool people](https://mitsurutech.co.uk/resources/t-level/dsd-8-2-social-engineering)

## What to do

Build a tiny checker. The first function finds the site name in a web address. The second says if the address is the REAL site: the whole name must match. The third counts warning words in a message.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
