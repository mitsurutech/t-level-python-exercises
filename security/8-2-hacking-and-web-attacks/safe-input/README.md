# Safe input: Python exercise for T Level Digital Software Development

> **From the lesson:** [8.2: Hackers and attacks on websites](https://mitsurutech.co.uk/resources/t-level/dsd-8-2-hacking-and-web-attacks)

## What to do

Fill in three functions. The first counts the combinations in a password. The second makes typed text safe to show on a page. The third checks a username.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
