# Doors: Python exercise for T Level Digital Software Development

> **From the lesson:** [8.2: Walk around the office: people and places](https://mitsurutech.co.uk/resources/t-level/dsd-8-2-office-walk)

## What to do

Write two functions. good_code checks a door code. It needs at least 6 digits. It must not be all the same digit. It must not be in the list of old codes. not_allowed_in checks an audit. It gets the names who entered and the names allowed. It gives back the names who should not have entered, in the order they entered.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
