# Backup maths: Python exercise for T Level Digital Software Development

> **From the lesson:** [8.3: Backups, updates and air gaps](https://mitsurutech.co.uk/resources/t-level/dsd-8-3-backups-and-updates)

## What to do

Work out backup sizes and restore steps. The first function gives the size of one night's backup. The second says how many pieces you need to restore.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
