# Locks: Python exercise for T Level Digital Software Development

> **From the lesson:** [8.2: Attacks on the way: DNS, Wi-Fi and APIs](https://mitsurutech.co.uk/resources/t-level/dsd-8-2-network-attacks)

## What to do

Write two functions. api_reply gets a key, the list of valid keys and some data. It gives back the data when the key is valid, and "denied" when it is not. wifi_advice gets two True or False values: does the network have a password, and does the site use https. Give back "safe" if both are true, "careful" if one is true and "avoid" if neither is.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
