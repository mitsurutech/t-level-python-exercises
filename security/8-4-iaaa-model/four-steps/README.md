# Four steps: Python exercise for T Level Digital Software Development

> **From the lesson:** [8.4: Identify, authenticate, authorise, account](https://mitsurutech.co.uk/resources/t-level/dsd-8-4-iaaa-model)

## What to do

Build the four steps of a small login system. Identify a user, check their password by its hash, decide what a role may do, and read the log of one person's actions.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
