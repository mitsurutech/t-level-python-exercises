# Build schedule: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 8.2: Planning a software change](https://mitsurutech.co.uk/resources/t-level/dsd-os8-2-plan-the-change)

## What to do

A team has a list of change requests. Each has a name, a priority (1 is the most urgent) and a number of days. schedule gives the names in the right order. Priority 1 goes first, then 2, then 3. For the same priority, the change with fewer days goes first. The function put_in_order is finished for you: it puts the requests in that order. Loop over it. fits goes down that order and adds each change while it fits in the days left. Stop at the first one that does not fit.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
