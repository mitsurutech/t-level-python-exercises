# Split it: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 8.3: Writing code a team can maintain](https://mitsurutech.co.uk/resources/t-level/dsd-os8-3-code-for-a-team)

## What to do

The receipt function does everything in one place. Split it into small functions. line_total gives price times quantity. basket_total adds all the lines. receipt_line gives text like Tea x2 = 3.00 (that is 2 teas at 1.50 each). Then rewrite receipt so it uses the small functions and gives the same text as before.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
