# Change log: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 8.3: Writing code a team can maintain](https://mitsurutech.co.uk/resources/t-level/dsd-os8-3-code-for-a-team)

## What to do

Write two functions for a change log. log_line makes one line like 2.0.1 (2026-10-02) [Fixed] Login accepts spaces. change_log joins the lines of many entries, newest day first. The function newest_first is finished for you: it puts the entries in order.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
