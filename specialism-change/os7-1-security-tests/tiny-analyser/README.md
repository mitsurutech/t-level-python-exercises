# Tiny analyser: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.1: Security testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-1-security-tests)

## What to do

Write a tiny static analyser. It gets the lines of a program as a list of text. It gives back the line numbers that have a problem. The first line is number 1. A problem is a line with password =, eval( or http:// in it. A line with two problems is listed only once.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
