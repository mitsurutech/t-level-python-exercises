# Fix ticket: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 8.4: Helping users: from ticket to fix](https://mitsurutech.co.uk/resources/t-level/dsd-os8-4-fix-user-issues)

## What to do

Ticket 231: the marks page shows an error for a class with no marks. You replicated it. Now fix it. average_mark gives 0 for an empty list. top_mark gives None for an empty list. Normal classes must still work.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
