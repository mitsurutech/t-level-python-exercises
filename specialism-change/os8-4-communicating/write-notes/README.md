# Write notes: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 8.4: Communicating with your users](https://mitsurutech.co.uk/resources/t-level/dsd-os8-4-communicating)

## What to do

Release notes tell users what changed, in plain words. Fill in release_notes. It gets a version and a list of changes, and gives back the text. The groups are New, Fixed and Changed, in that order. Leave out a group with no items. Read the starter for an example.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
