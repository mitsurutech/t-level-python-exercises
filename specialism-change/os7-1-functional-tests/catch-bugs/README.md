# Catch bugs: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.1: Functional testing: unit to system](https://mitsurutech.co.uk/resources/t-level/dsd-os7-1-functional-tests)

## What to do

A bus company has a fare function. A child under 16 pays 1.0. Everybody else pays 2.5. You do not write the function. You write the checks. Fill in check_fare with assert lines. Your checks must pass the good one and catch every wrong one.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
