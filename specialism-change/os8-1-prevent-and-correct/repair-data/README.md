# Repair data: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 8.1: Maintenance: prevent and correct](https://mitsurutech.co.uk/resources/t-level/dsd-os8-1-prevent-and-correct)

## What to do

A bad update damaged some rows in the customer list. Each row is a customer id and an age. A good age is a whole number from 0 to 120. Fill in two functions. find_corrupt gives the ids of the damaged rows. repair gives a new list without the damaged rows. Do not change the original list.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
