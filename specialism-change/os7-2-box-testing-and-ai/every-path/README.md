# Every path: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.2: Closed box, open box and AI testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-2-box-testing-and-ai)

## What to do

You can see the grade function in the starter. This is open box testing. Fill in inputs_for_every_path. It gives a list of scores. Together they must reach all four paths: invalid, pass, near and fail. Also include 50 and 40, where the answer changes. Include one score below 0 and one score above 100.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
