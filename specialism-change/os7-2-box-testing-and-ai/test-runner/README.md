# Test runner: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.2: Closed box, open box and AI testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-2-box-testing-and-ai)

## What to do

Write a tiny automatic test runner. A case is a pair: the input and the answer you expect. failed_cases calls the function for each case and gives back the cases that did not match. all_pass says True when nothing failed.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
