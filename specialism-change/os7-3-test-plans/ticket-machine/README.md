# Ticket machine: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.3: The test plan and re-testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-3-test-plans)

## What to do

The ticket machine code has four bugs. The test plan found them. Read the rules at the top of the starter, then fix the code. All four tests must pass at the end. A fix that breaks a test you passed before is a regression: find and fix that too.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
