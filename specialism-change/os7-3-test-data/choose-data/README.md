# Choose data: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.3: Test data: normal, edge and wrong](https://mitsurutech.co.uk/resources/t-level/dsd-os7-3-test-data)

## What to do

Now you are the tester. For any range from low to high, choose the test data. normal_value gives a value inside, not on an edge. valid_extreme gives the two edge values. invalid_extreme gives one value just below and one just above. erroneous_examples gives three or more pieces of text that are not numbers.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
