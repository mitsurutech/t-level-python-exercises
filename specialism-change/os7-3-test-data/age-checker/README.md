# Age checker: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.3: Test data: normal, edge and wrong](https://mitsurutech.co.uk/resources/t-level/dsd-os7-3-test-data)

## What to do

Write the checker for the college form. check_age gets what the user typed, as text. Give back "ok" for a whole number from 16 to 19. Give back "wrong range" for a whole number outside that. Give back "not a number" if the text is not a whole number. For us, 16.5 is not a whole number.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
