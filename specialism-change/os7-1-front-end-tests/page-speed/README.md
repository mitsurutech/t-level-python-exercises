# Page speed: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.1: Front-end testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-1-front-end-tests)

## What to do

A page loads files of different sizes. Fill in three functions. loading_time divides the size by the speed. too_slow says if the time is over the limit. heaviest_file gives the name of the biggest file in a dictionary.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
