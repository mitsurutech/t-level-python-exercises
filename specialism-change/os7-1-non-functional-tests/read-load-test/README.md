# Read load test: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.1: Non-functional testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-1-non-functional-tests)

## What to do

A load test gives a list of response times in seconds. Fill in four functions. slowest gives the biggest time. slow_count counts the users who waited more than the limit. average_time adds the times and divides by how many there are. passed is True when the number of slow users is not more than allowed_slow.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
