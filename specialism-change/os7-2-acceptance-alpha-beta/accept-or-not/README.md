# Accept or not: Python exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.2: Acceptance, alpha and beta testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-2-acceptance-alpha-beta)

## What to do

A college asks for a timetable app. Each requirement is a group of three things: the text, True or False for must-have, and True or False for passed. Fill in two functions. accepted gives True when every must-have requirement passed. not_met gives a list of the texts of all requirements that did not pass, in order.

## Starter files

- `main.py`

Write your answer in `main.py`. To try it, add a few `print(...)` lines at the bottom and run `python3 main.py`.
